# 무결성과 정합성

사용자의 최신 답변에 따라 전원 퇴각의 손실 대상은 무결성으로 확정했다. 각 100% 사용자 HP, 생존 적당 -10%p, 정합성 손실 이월 API, 무결성 0% 사출/저장 종료, Map 기존 TMP 숫자 표시를 구현했다. 대원 HP와 퇴각의 전투 간 비이월 정책은 유지한다.

## 검증

- `RunRecordVerification.RunFinal`: 기존 Cache/진행/HP/SP/카드/맵 enum·JSON·저장 회귀와 새 HP 경계/음수/초과 손실/저장 왕복/v1 호환/종료 차단/새 게임 초기화 통과.
- `RunRecordPlayVerification`: Map 상태 → 적 3명 생존 패배 → 무결성 70%로 Map → 새 전투의 대원 초기화 → 무결성 소진 → Lobby/계속하기 차단 → 새 게임 100% 초기화 제한 시나리오 통과 (종료 코드 0). 정합성은 테스트 API로 80%를 만들었고 두 전투 동안 그대로 유지됨을 확인했다.
- 최초 플레이 시도는 테스트가 연결 노드를 건너뛰어 기존 이동 제한에 막혔다. 검증 경로를 1→2→5로 수정했으며 게임 이동 규칙은 바꾸지 않았다.
- 저장소는 임시 폴더로 격리했다. 실제 사용자 세이브를 읽거나 삭제하지 않는다. 실제 포인터/해상도별 시각 QA는 수행하지 않았다.

정합성 감소 원인과 최종 엔딩은 의도적으로 미연결이다. 기존 사용자 폰트·Obsidian workspace 변경은 커밋에서 제외한다.
