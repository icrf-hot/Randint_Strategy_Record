# 2026-10-15 추가 결정과 구현

## 사용자 결정

- 퇴각은 전투 Scene 한정. Map과 다음 전투로 이월하지 않는다.
- 임시 7종을 별도 Shop Scene에서 판매, AI가 8~32 Packet 가격 책정.
- 보상 Cache +50%, 승리 Packet/획득 EXP에 반올림 적용. Layer 상승 Packet 및 요구 EXP 제외.
- 원본 고유 스탯 기준 합연산. 모든 합산 후 곱연산 상위 Cache는 미래 작업.
- Back Healer: (a+b)×100. 자연 SP: 아군/적의 실제 공격 횟수. 상세 스킬 효과 보류.
- 저장은 전투 밖에서 사이클 전체(아군/Cache/맵 등). 종료한 판의 이어하기 금지. 무결성/정합성 세부값은 보류.

## 완료 1: 가격과 승리 보상

- HP12/공격16/방어12/저항8/속도20/종합32/보상24 Packet. 카탈로그 7종 모두 설정 완료.
- 승리 Packet/EXP 퍼센트는 구매한 보상 Cache에서 합산한다. 정수 반올림은 AwayFromZero. 보상 전체 검증 후 지갑과 EXP를 반영한다.
- 기존 가격 의존 검증을 새 가격에 맞췄다. `CodexCacheRewards.log` 구매/실패 원자성/Cache 보상 검증 통과.

## 완료 2: Healer와 자연 SP

- Healer만 승인된 Back 카드의 (a+b)×100을 기존 회복 대상에 적용. 다른 세부 직군은 임시 동작 유지.
- 실제 Front/Middle/Enemy 공격 직후 전역 자연 SP 통지. 활성 아군 Natural 스킬만 충전하고 취소/방어/회복 제외. 최대 SP와 회복 합산 오버플로 방지.
- `CombatRulesVerification.Run`, `CodexCombatRules.log` 종료 코드 0. 순수 공식, 7회 통지 중 적 실제 공격 경로 4회, 취소/퇴각/상한 확인. 전체 전투 플레이 검증과 구분한다.
- 가격/보상 작업은 `2337793` 커밋·푸시 완료. `CodexRewardRounding.log`에서 0.5 반올림·보상/다중 Layer/오버플로 검증도 통과.

## 완료 3: 별도 Shop Scene

- 새 Shop.unity와 Build Settings 등록. MapChoice에서 Shop 선택 시 Scene을 열고 맵으로 복귀한다.
- 기존 한글 TMP 폰트와 Input System UI 모듈을 사용하는 7종 스크롤 목록, 가격/강화량/잔액, 구매·거절, 판매 완료·잔액 부족 비활성, 맵 복귀를 구현했다.
- CodexShopRoundTrip.log 제한 플레이 1회 통과: 맵 선택지→상점 UI 구매(12 Packet)→중복/잔액 부족 거절→맵 노드8 복귀→재입장 상태 유지. 실제 마우스·해상도별 시각 QA는 미실시.
- 테스트에서 생성한 공유 폰트 커닝만 제외했다. 사용자 기존 wiki 변경은 보존한다.
- 완료 2는 8129074로 커밋·푸시 완료.
