# 사건 임시 보상과 루트별 종료 정산

## 사용자 확정

- Q-E01: 추후 선택별 Packet·HP·Cache/유물·루트 유물·특수 전투로 확장한다. 현재는 무결성·정합성 각각 +2%p를 임시 보상으로 사용한다.
- Q-R01: 승패와 관계없이 전투 노드는 소모하며 재도전하지 못한다. 일반 패배는 생존 적 1명당 무결성 −10%p다.
- 일반 루트는 3층 보스에서 엔딩, 히든 루트는 4층을 거쳐 5층 보스에서 엔딩이다. 이 결정이 과거의 ‘5층 노멀/6·7층 히든’ 진행안을 대체한다. 6·7층은 구현하지 않는다.
- 일반 3층 보스 패배는 작전 패배로 종료한다. 히든 3층 보스 패배는 생존 적당 −20%p를 적용하고, 무결성이 남으면 4층으로 넘어간다.
- 무결성 0%면 정합성 잔량과 관계없이 완전 패배한다. 히든 3층의 진행 예외보다 우선한다.
- 종료 시 클리어/패배를 명시한 상태창에서 유물과 대원별 스탯을 보여주고, 확인 후 Lobby로 돌아간다. 자동으로 읽을 시간을 제한하지 않는다.

## 구현

`MapRunState`의 `HiddenEndingRouteUnlocked`와 `EndingFloor`로 일반 3층/히든 5층을 분리했다. 이후 조건이 정해지면 `TryUnlockHiddenEndingRoute()`를 사건/유물 결과에서 호출할 수 있다. 현재 플레이에서 임의로 해금시키는 조건은 추가하지 않았다. Editor에서 4·5층 Scene을 새 판으로 직접 시작하는 경우만 히든 상태로 초기화한다.

마지막 노드를 완료하고 상점·유물 창을 닫으면 다음 층으로 자동 전환한다. 수동 다음 층 버튼은 제거했다. 일반 3층·히든 5층 승리는 `Ending`, 마지막 노드 전투 패배는 `TerminalDefeat`, 무결성 소진은 `Ejected`로 종료한다. 동일 판의 저장 사본을 종료 처리하여 계속하기를 막는다.

`RunEndSummary`는 구매 이력과 현재 보유 목록을 따로 이름순 정렬하고, 편성 대원을 FRONT→MIDDLE→BACK 순으로 출력한다. 각 대원의 HP/ATK/DEF/RES/SPD는 기본→유물 적용 수치, 가산량, 기본 대비 보정률을 표시하며 보정률 내림차순으로 정렬한다. 기본값 0은 가산량을 표시하고 비율 산정 불가로 표기한다. 실제 전투와 동일한 `CacheStatBonuses`를 사용하며 종료 시 사라지는 라운드 임시 보너스는 포함하지 않는다. `RunSummaryWindow`는 공통 uGUI/UITheme 기반 스크롤 창이다.

새로 배정되는 사건은 `EncounterTier.temporaryRewardHp=2`를 읽는다. 보상을 주는 선택의 Packet/기존 회복 보상을 두 HP +2%p로 대체한다. 검증·거래·위조의 기존 비용은 유지하며 비용 적용 후 회복하고 100%로 제한한다. 검증만 하는 단계와 떠나기에는 회복이 없다. 기존 저장 사건은 복사된 티어의 값 0을 유지하여 이미 약속한 예전 보상을 받는다. 임시 균일보상에 맞춘 비용 재조정과 다양한 실제 보상 타입은 추후 작업이다.

## 저장 호환

v6에 `hiddenEndingRouteUnlocked`를 추가했다. v1~v5를 읽으며 원본 파일은 변경하지 않는다. 예전 4·5층 진행 저장은 진행을 보존하도록 히든으로 준비 복원하고, 1~3층은 일반으로 복원한다. 예전 마지막 패배 노드가 미완료이면 완료 목록에 보완한다. 예전 파일에는 이전 패배 전체 이력이 없으므로 마지막 패배 이외의 과거 전투를 추측해 변경하지 않는다. v6의 4·5층 저장은 히든 플래그가 없으면 거절한다.

## 검증

- Unity 6000.3.11f1의 이 프로젝트 Main Editor를 지정해 C# 컴파일 확인.
- `RunResolutionVerification`: 패배 노드 소모·구 저장 이관·일반/히든 종료·두 배 손실·무결성 0 우선·임시/예전 보상·소유/구매 분리·스탯 보정률 정렬 통과.
