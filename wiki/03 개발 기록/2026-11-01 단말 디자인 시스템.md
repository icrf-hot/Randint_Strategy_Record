# 2026-11-01 기록 열람 단말기 디자인 시스템

## 구현 범위

기존 Unity 6000.3.11f1 / uGUI / URP 프로젝트의 게임 데이터, 저장 구조, 씬 참조를 유지하며 기존 화면을 직접 수정했다. Title, Lobby, Preparation, Map_1F, Playing_Scene, Shop에 공통 테마를 적용했다.

### 공통 기반

- `Assets/Script/UI/UITheme.cs`: 지정된 10색 팔레트, 투명도, 테두리, 효과 시간, 파티클 상한의 단일 정의.
- `Assets/Resources/UITheme.asset`: 기존 Cafe24 제목 폰트와 JetBrains Mono 폰트 참조. 기존 폰트 소스는 교체하지 않는다.
- `Assets/UI/Terminal`: Panel, ButtonDefault, ButtonEmphasis, ButtonDanger, ButtonStart, Label, ProgressBar, Tag 프리팹.
- 기존 씬의 Graphic에는 UIThemeBinding, 단색 Sprite에는 TerminalSpriteBinding을 연결한다. 일러스트의 원래 색은 중립 텍스처 배율로 보존한다.
- 기본 버튼은 투명 배경과 accent 라인, 카드의 기본 테두리는 line, hover는 accent. pressed/disabled 상태 및 0.08초 보간, 얇은 외곽 글로우와 클릭 사운드 이벤트 훅을 제공한다.

### 화면

- 타이틀: 자간 +4 모노스페이스 접근 라벨, 0.6초 등장 스캔과 3프레임 색 분리, 격자/스캔라인. 기존의 가짜 수백만 건 카운터는 실제 초기화 3단계 완료 수로 바꾼다. 세 검사가 성공한 후 접속 버튼을 활성화한다.
- 관리 화면: 어두운 단말 바탕화면, 28px 타이틀바, 라인 아이콘, 동일한 LayoutElement 가중치로 3카드 균등 배치, 1px hover 상승, 2초 주기 연결 점.
- 준비 화면: FRONT/MIDDLE/BACK 표기 수정, 포지션 Tag, 일러스트 발밑 글로우, 클래스 아이콘, 실제 HP/ATK/DEF, 우측 슬라이드 목록, 신규 런의 손실률 0%, STAGE 00, 편성 안내와 시작 버튼 상태.
- 맵: 실사 배경/기존 배경 표시 제거, 카메라 투영에 대응하는 원근 그리드, 종류별 홀로그램, 현재 위치의 발광 큐브와 트레일.
- 전투: 어두운 단색 표면과 카드 셰이더, 파티클, 모니터 후처리, 피해/처치 이벤트의 0.15초 흔들림과 조각 방출. 손패를 화면 안쪽으로 배치하고 좌하단 상태 패널을 위한 영역을 확보한다.
- HUD: 무결성/일관성 라벨·고정폭 값·상태를 HorizontalLayout으로 분리. 위험 상태와 무결성 막대, 우상단 패킷·레이어·경험치 패널/막대, 수치 변경 펄스.
- 설정: ESC 및 톱니 버튼, 모니터 효과/동작·깜빡임 옵션 저장. 전투 설정 화면은 일시정지와 원래 배율 복귀를 처리한다.
- 상점 및 저장 UI의 동적 생성 요소도 테마를 사용한다.

### 전환

`TransitionManager`가 모든 제품 코드의 SceneManager.LoadSceneAsync 호출을 소유한다. 기존 MenuSceneLoader, MapBattleSceneLoader, BattleToMapSceneLoader, ShopSceneRouter와 저장 후 로비 복귀·레거시 진입점은 이 관리자로 위임한다.

0.25초 스캔 와이프와 한 줄 로그, 0.3초 AudioSource 볼륨 페이드, 전환 중 UI/직접 입력 차단, 중복 요청 거부를 제공한다. 전환 전 대상 검증, 로드 시작 실패 시 입력·볼륨·배율 복구를 처리한다. 맵/전투의 IsFadeComplete 진입 계약은 호환 클래스로 유지한다.

## 데이터와 범위에 대한 결정

- 현재 정의된 대원은 포지션별 1명, 총 3명이다. 목록은 실제 등록 대원을 보여주고 현재 편성을 유지한다. 존재하지 않는 대원을 생성하거나 저장 포맷/전투 편성 규칙을 확장하지 않았다.
- RANGE 데이터가 없어 실제 데이터가 있는 DEF를 표시했다.
- 타이틀 숫자는 실제 초기화 단계 수이다. 표시용 가짜 진행률이나 임의 작업 건수를 만들지 않았다.
- 체스말은 맵에 존재한다. 홀로그램은 실제 맵 오브젝트에 적용하며, 전투 캐릭터 일러스트는 보존한다.
- 환경 파티클과 처치 조각은 씬당 하나의 ParticleSystem을 공유하며 maxParticles=200이다.
- 클릭 효과음은 이벤트 훅을 제공한다. 실제 사운드 클립의 선택·믹싱 평가는 포함하지 않는다.

## 검증

- C# 컴파일 오류 0.
- 셰이더 3종 지원 및 컴파일 오류 없음, 고정폭 숫자 10종의 advance 일치 확인.
- 공통 컴포넌트 프리팹 8종, 6개 씬의 누락 스크립트 없음, 기존 화면의 테마 바인딩 137개 확인.
- `TerminalThemeVerification.Run()`은 지정 시에만 실행하는 실제 Play Mode 점검이다. 저장 파일을 작성하지 않으며 결과/캡처는 기본적으로 프로젝트 `Temp/TerminalVerification`에 쓴다.
- 확인 항목: 실제 부팅/버튼 활성화, 균등 카드 폭, 편성 데이터/목록, 맵 HUD, 전투·상점 왕복, 로비 복귀, 배율 복원, 잘못된 씬 요청과 중복 전환 거부, 설정 일시정지/모니터 옵션, 무결성 25% 위험 표시, 파티클 상한, 손패 화면 내 배치.
- 대표 화면은 1920×1080 캡처로 확인한다. 전체 전투 밸런스, 캠페인 완주, 실기기 성능 프로파일링 및 출시 빌드 검증은 이번 UI 검증과 별개다.

## 사용자 피드백 반영: 설명창·전장·전방향 배경

- 캐릭터 설명창의 배경 불투명도를 UITheme.InfoPanelOpacity=0.45로 변경. 텍스트와 로고에는 별도 전체 투명도를 적용하지 않는다.
- Playing_Scene의 Ground(0.4339623)와 UnderGround(0.2924528)를 이전 백업의 회색으로 복원. 후방의 어두운 단말 배경과 HUD 개선은 유지한다. 회색도 UITheme의 별도 토큰으로 관리한다.
- 이전 구현의 카메라 방향을 따르는 바닥 그리드·수평선 생성 코드는 제거했다.
- 국소적인 배경 파티클 묶음을 제거하고 TerminalStarfield Skybox로 전방향 별 배경을 표시한다. 카메라 전용 Skybox 오버라이드까지 적용해 기존 실사 은하수 텍스처가 앞에 표시되지 않도록 한다. 동작 줄이기 설정에서는 반짝임을 정지한다.
- 하나의 maxParticles=200 ParticleSystem은 피격/처치 조각용으로 유지한다.
- 검증: C# 컴파일, 별 배경 셰이더 검사, 저장된 바닥 색/설명창 알파 검사, 실제 맵 120도 회전과 설명창 열기 캡처, 화면 왕복 회귀 검증 통과.
