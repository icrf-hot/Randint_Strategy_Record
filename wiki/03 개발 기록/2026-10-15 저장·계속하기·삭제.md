# 저장·계속하기·삭제

## 완료

Map 수동 저장/저장 후 로비, Lobby 실제 파일 요약/계속하기/두 단계 삭제를 연결했다. 런 대원 ID·Cache 소유/구매 이력·Packet/Layer/EXP·현재/방문/완료 노드·마지막 전투 결과를 저장한다. 전투의 HP·퇴각은 이월하지 않는다.

버전·JSON·체크섬·참조·값 검증 후 준비된 상태만 복원한다. 임시 파일 완성 후 교체하고 백업을 유지한다. 전투/전환 저장 금지와 종료 판 복원 거절을 추가했다. UI 문구는 JSON이며 로비 재생성 도구와 참조 검사도 갱신했다.

## 검증

- `RunSaveVerification`: 파일 왕복, 초기화 후 전체 복원, 잘못된 데이터 거절과 기존 파일/메모리 보존, 손상·체크섬·크기 제한·IO 오류, 백업 생성, 종료 판 차단, 삭제의 멱등성.
- `RunSavePlayVerification`: UI 이벤트 기반 Map 저장/저장 후 로비 → 메모리 소실 후 계속하기 → 전투 저장 차단/새 대원 HP → Map → Lobby 삭제 확인/취소/완료. 임시 저장소로 격리했다.
- 최종 기존 Cache/진행/HP/SP/카드/맵 enum 및 JSON/Scene 참조 회귀 검증 통과 (`RunSaveVerification.RunFinal`, 종료 코드 0).

## 남은 범위

실제 포인터·해상도 QA, Q-R03 엔딩/사출 조건과 종료 훅 호출 연결. 새 게임은 기존 슬롯을 자동 삭제하지 않는다. 단일 슬롯/명시적 저장이며 자동 저장·다중 슬롯은 추가하지 않았다. 기존 사용자 폰트 변경은 커밋에서 제외한다.
