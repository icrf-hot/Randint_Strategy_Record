# 씬과 코드 구조

## 씬 구성

### Title

- GameObject 1개: `Main Camera`
- 게임 시작 UI와 씬 전환 로직은 아직 확인되지 않음

### Map_1F

- 127개 GameObject
- `MapNode` 8개
- 각 노드의 설명·선택지, 노드 포커스 UI, 궤도 카메라, 현재 위치 피드백 포함
- Battle 노드에서 전투 씬을 부르는 `MapBattleSceneLoader`와 `LoadingCanvas` 포함
- 주요 오브젝트: `Map3DCamera`, `MapCameraTarget`, `NodeClickManager`, `MapUI_Root`, `MapLoader_BattleScene`

### Playing_Scene

- 약 212개 GameObject
- 대원 3명, 포지션 선택 UI, 카드 공급/선택, 전투 승인/실행, 적 생성/타기팅, 디버그 피해 UI 포함
- `BattleEntryCanvas`와 `SceneFadeIn_Manager`가 진입 중 시간을 정지하고 입력을 차단한 뒤 화면을 연다.
- 주요 루트: `CharacterSet`, `EnemySet`, `CardSelection`, `AccessManager`, `Manager`

## 코드 트리

```text
Assets/
├─ Script/
│  ├─ AttackButton/       전투 실행·공격 계산 버튼
│  ├─ AttributeButton/    Middle 물리/마법 모드 UI
│  ├─ ButtonEffect/       Sprite 기반 버튼·토글 효과
│  ├─ CardScript/         카드 상태·위치·애니메이션
│  ├─ CardSelection/      Front/Middle/Back 선택과 전투 승인
│  ├─ Debug/              대원 피해 디버그
│  ├─ Enemy/              적 데이터·스폰 위치·타기팅
│  ├─ Operator/           대원 데이터·포커스·회복 타기팅
│  ├─ Skill/              스킬 데이터와 런타임 SP 모델
│  ├─ AttackCalculator.cs
│  ├─ BattleSceneFadeIn.cs
│  ├─ CardSpawner.cs
│  └─ EnemySpawnManager.cs
├─ Map/
│  ├─ Script/             노드·선택지·위치 피드백·표시·전투 씬 로더
│  └─ Script 1/           궤도 카메라
├─ OperatorData/          대원 ScriptableObject
├─ SkillData/             스킬 ScriptableObject
├─ Prefab/                카드·대원·적·맵 노드 프리팹
└─ Scenes/                Title, Map_1F, Playing_Scene
```

## 런타임 관리자

| 관리자 | 책임 |
|---|---|
| `CardSpawner` | 진입 페이드 완료 후 첫 카드 배분, 이후 카드 회수·교체 |
| `CardPositionManager` | 카드 클릭을 현재 포지션 선택기로 전달 |
| `BattleAccessManager` | 전투 실행 가능 조건 통합 |
| `BattleExecuteManager` | 턴 목록 생성·정렬·실행·라운드 정리 |
| `EnemySpawnManager` | 지정 위치에 적 생성 |
| `EnemyTargetingManager` | 대원별 적 타깃 선택·복원 |
| `AllyTargetingManager` | 자동 회복 대상 우선순위 |
| `OperatorFocusManager` | 카메라·시간 감속·대원 정보 UI |
| `MapPlayerPositionFeedback` | 현재 노드와 이동 가능 상태 |
| `MapOrbitCamera` | 맵 회전·노드 포커스·복귀 |
| `MapBattleSceneLoader` | Battle 노드의 로딩 오버레이와 비동기 전투 씬 전환 |
| `BattleSceneFadeIn` | 전투 진입 문구·화면 페이드, 입력 차단과 게임 시간 복원 |

## Build Settings

현재 활성화된 씬은 다음 두 개다.

1. `Assets/Scenes/Map_1F.unity`
2. `Assets/Scenes/Playing_Scene.unity`

`Title.unity`는 프로젝트에 존재하지만 Build Settings에는 등록되어 있지 않다.

## 결합 방식

현재 시스템은 Unity 직렬화 참조와 여러 `Instance` 싱글턴, `FindFirstObjectByType`/`FindObjectsByType`를 함께 사용한다. 프로토타입 단계에서는 빠르게 연결할 수 있으나, 씬이 커질수록 초기화 순서와 누락 참조를 별도 점검해야 한다.
