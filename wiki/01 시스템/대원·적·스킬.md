# 대원·적·스킬

## 대원 데이터 모델

`OperatorData` ScriptableObject는 JSON 정의 ID를 보관한다. 이름·소개는 문구 키로 조회하고 포지션·직군·타깃 조건·기본 능력치·`skillIds`는 `Definitions/operators.json`에서 읽는다. `Operator.Awake()`는 기본값으로 현재 HP와 능력치·스킬 인스턴스를 초기화한다. HP·SP·퇴각·예약 재배치·임시 보너스는 JSON에 저장하지 않는다.

### 포지션별 허용 클래스

| 포지션 | 허용 클래스 |
|---|---|
| Front | Defender, Guard, Vanguard |
| Middle | Caster, Sniper |
| Back | AttackHealer, Healer, Supporter |

JSON Catalog 검증은 잘못된 포지션·직군 조합을 오류로 처리한다. 이전 Inspector 자동 교정 방식은 제거되었다.

## 대원 포커스 UI

대원 클릭 시 `OperatorFocusManager`가 다음을 수행한다.

- 시간을 기본 `1.0`에서 `0.2`로 감속
- 포지션별 카메라 포커스 지점, 줌, 회전값으로 보간
- World Space 정보 UI에 이름, 설명, HP, 공격, 방어, 저항, 속도를 표시
- 적 타깃이 필요한 대원이면 `EnemyTargetingManager.BeginTargeting()` 호출
- 다른 대원 클릭 시 정보 패널을 빠르게 숨긴 뒤 내용 교체

## 퇴각·부활·재배치

- HP 0 시 GameObject를 파괴하지 않고 `Retreated` 상태와 어두운 시각 표현으로 유지한다.
- 퇴각 대원은 행동·일반 타기팅·포커스 클릭에서 제외하며 카드·행동·타깃 승인을 요구하지 않는다.
- `Revive`·`ScheduleRedeployment`·`ProcessRedeploymentTurn`과 관련 이벤트 훅은 있으나 실제 스킬/예약 정책 호출은 미연결이다.
- `AllyTargetable.TargetCollider` 공개 속성과 `CanBeRevivalTarget`이 존재한다. 부활 UI는 아직 없다.

## 적 생성과 위치

`EnemySpawnManager`가 지정 인덱스의 `EnemySpawnPoint`에 적 프리팹을 생성한다. 스폰 지점은 `FrontLeft`, `FrontRight`, `BackLeft`, `BackRight` 위치를 갖고, 생성된 `EnemyTargetable`에 위치가 전달된다.

적 프리팹은 `dataId: makeshift`를 보관하며 실제 스탯은 `Definitions/enemies.json`에서 읽는다.

## 적 타기팅

- Front 대원은 `FrontLeft`와 `FrontRight`만 선택 가능
- Middle과 Back 대원은 모든 위치 선택 가능
- 타깃은 대원별 딕셔너리에 따로 기억됨
- 같은 적을 다시 클릭하면 선택 해제
- 죽거나 존재하지 않는 적은 저장된 선택에서 제거
- 타기팅 가능/불가/선택 상태를 색과 인디케이터로 표현

## 회복 타기팅

Back 행동은 수동 대상 선택이 아니라 `AllyTargetingManager`의 자동 우선순위를 쓴다.

1. 퇴각하지 않았고 HP가 가득 차지 않은 대원을 후보로 수집한다.
2. HP 비율 오름차순으로 정렬한다.
3. 기본 설정에서는 최대 2명을 선택한다.
4. `SelfPriority` 설정이면 힐러 HP가 임계값 이하일 때 힐러 자신을 먼저 포함한다.

## 스킬

`SkillData`는 JSON 스킬 ID를 보관하며 이름·설명·SP 정의를 조회한다. 대원의 스킬 연결은 `operators.json`의 `skillIds`로만 지정한다. 현재 세 대원의 목록은 모두 비어 있다. `OperatorSkill`은 다음 SP 충전을 지원한다.

- `Natural`: 전달받은 공격 횟수 × 충전량
- `Attack`: 공격 시 충전량 추가
- `DamageTaken`: 피격 시 충전량 추가
- 최대 SP 도달 시 `IsReady == true`
- 활성화 후 SP 초기화

> [!warning] 부분 구현
> 대원은 시작 시 스킬 런타임 객체를 만들지만, 현재 전투 행동·공격·피격 코드가 SP 충전 메서드나 `Activate()`를 호출하지 않는다. `Activate()` 내부 효과도 로그와 SP 초기화만 있으며 실제 `SkillEffect`는 없다.
