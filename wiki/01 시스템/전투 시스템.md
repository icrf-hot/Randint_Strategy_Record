# 전투 시스템

> [!implemented] 🟢 구현
> 카드 승인부터 속도 기반 행동 실행, 생존 적 검사, 승리 시 맵 복귀 또는 다음 카드 배분까지 연결되어 있다.

## 진입 조건

`BattleAccessManager.Refresh()`가 아래 조건을 모두 만족할 때만 전투 버튼을 활성화한다.

- 세 선택 매니저와 Front/Middle/Back 대원이 모두 존재
- 세 포지션의 카드 선택이 완료
- Front 행동이 공격 또는 방어로 결정
- 공격 행동을 하는 대원에게 필요한 적 타깃이 선택됨
- 전투 코루틴이 실행 중이 아님

Front가 **방어**를 선택하면 적 타깃이 필요 없다. `RequiresEnemyTarget == false`인 대원도 타깃 검사에서 자동 통과한다.

## 실행 순서

```mermaid
sequenceDiagram
    participant UI as 전투 버튼
    participant Access as BattleAccessManager
    participant Exec as BattleExecuteManager
    participant Focus as OperatorFocusManager
    participant Actor as Operator / Enemy
    participant Cards as CardSpawner

    UI->>Exec: ExecuteBattle()
    Exec->>Access: CanBattle 확인
    Exec->>Cards: 회수 애니메이션 시작
    Exec->>Exec: 아군 3명 + 생존 적 행동 생성
    Exec->>Exec: 속도 내림차순 정렬
    loop 행동 목록
        Exec->>Focus: 아군 행동 전 자동 포커스
        Exec->>Actor: 행동 실행
        Exec->>Exec: 생존 적 검사
    end
    alt 모든 적 처치
        Exec->>Exec: 일반 라운드 정리 중단
        Exec->>Exec: 맵 복귀 로더 호출
    else 적 생존
    Exec->>Focus: 포커스 종료
    Exec->>Actor: 임시 보너스 초기화
    Exec->>Cards: 회수 완료 대기
    Exec->>Access: 선택 초기화 후 새 카드 배분
    end
```

## 턴 우선순위

1. `AttackSpeed`가 높은 개체가 먼저 행동한다.
2. 속도가 같으면 `TiePriority`가 낮은 순서다.
3. 아군 동률 우선순위는 Front `0` → Middle `1` → Back `2`다.
4. 적은 `100 + EnemyPosition`을 사용하므로 같은 속도에서는 아군 뒤에 행동한다.
5. 자기 차례에 HP가 0이면 행동을 건너뛴다.

## 포지션별 행동

| 포지션 | 행동 | 결과 |
|---|---|---|
| Front | 공격 | 선택 숫자 × 100을 공격 보너스로 더한 뒤 물리 피해 |
| Front | 방어 | 선택 숫자 × 5를 방어력과 마법 저항에 임시 추가, 공격하지 않음 |
| Middle | 공격 | 선택 속성/모드의 공식 결과를 공격 보너스로 더한 뒤 물리 또는 마법 피해 |
| Back | 회복 | HP 비율이 낮은 아군을 최대 2명까지 각각 50 회복 |
| Enemy | 공격 | 생존한 Front → Middle → Back 순으로 첫 대상을 물리 공격 |

## 피해 공식

```text
물리 최종 피해 = max(1, 공격력 - 대상 방어력)
마법 최종 피해 = max(1, 공격력 - 대상 마법 저항)
```

대원의 전투 중 유효 능력치는 `기본 현재값 + 해당 라운드 임시 보너스`다. 라운드가 끝나면 임시 보너스가 0으로 초기화된다.

## 라운드 종료

- 대원 포커스 해제
- 세 대원의 전투 보너스 초기화
- 카드 회수 애니메이션 완료 대기
- Front/Middle/Back 선택 초기화
- 기존 카드 파괴 후 새 카드 배분
- 전투 실행 잠금 해제

## 승리와 종료

- 각 행동 코루틴이 끝난 다음 프레임에 `AreAllEnemiesDefeated()`를 호출한다.
- 씬의 모든 `Enemy`가 없거나 HP가 0이면 승리로 처리한다.
- 승리 시 `ReturnToMap()`이 중복 실행을 막고 전투 입력·포커스를 닫은 뒤 `BattleToMapSceneLoader`를 호출한다.
- 승리 분기는 일반 라운드 정리와 새 카드 배분을 건너뛰고 씬 전환으로 종료된다.
- 아군 전멸에 대한 패배 판정과 웨이브 진행·재생성 정책은 아직 없다.
