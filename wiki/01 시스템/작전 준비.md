# 작전 준비

## 진입과 확정

Title → Lobby → 새 게임 → Preparation → 작전 시작 → Map → Playing 순서다. 기존 로비와 맵을 생략하지 않는다. 저장된 게임의 계속하기는 준비를 건너뛰고 저장된 Map 상태를 복원한다.

Preparation 진입과 로비 복귀는 기존 메모리 판/저장을 초기화하지 않는다. 작전 시작을 확정했을 때만 기존 새 게임 초기화를 수행한다. 세 포지션의 편성은 RunSaveBindings의 기본 대원 ID를 사용하므로 실제 전투/저장과 동일하다.

## 현재 제공 범위

- Front: 사리아, Middle: 도로시, Back: 조이스 무어. 기존 캐릭터 이미지와 이름 JSON을 사용한다.
- 각 대원의 변경 버튼은 오른쪽 대원 목록 서랍을 연다. 현재 포지션에 등록된 기존 대원만 보여 주며 “현재 편성 유지”로 닫는다. 자유 교체/추가 대원은 구현하지 않는다.
- 데이터 손실률은 사용자가 선택할 런 디버프 단계의 이름이다. 지금은 0단계만 표시하고 상위 단계/실제 디버프는 구현하지 않는다.
- 0단계 외의 값이 존재하지 않으므로 이번에는 저장 형식이나 전투 수치를 바꾸지 않는다. 상위 단계 도입 시 런 상태/저장/복원과 규칙 정의를 함께 확장해야 한다.

## 구현

Scene: Assets/Scenes/Preparation.unity, Build Index 5. 기존 씬 인덱스는 보존한다. PreparationSceneController는 진입/확정/경고를 담당하고 MenuSceneLoader의 기존 전환을 재사용한다. PreparationSceneBuilder는 Editor API로 새 씬을 생성하며 이미 있는 씬을 덮어쓰지 않는다. 문구는 Resources/GameData/Localization/ko-KR/preparation.json이다.

최초 준비 씬 작업은 컴파일·정적 대조만 수행했다. 이후 단말 디자인 시스템 작업에서 실제 준비 진입·능력치·서랍 열기/닫기·작전 시작 경로를 제한 검증하고 캡처했다. 다양한 해상도와 전체 마우스 조작 전수 검사는 남아 있다.

TerminalPreparation이 포지션 Tag, 클래스 표시, HP/ATK/DEF, 데이터 손실률 0% 막대와 STAGE 00 / 도입 구간 표기를 추가한다. [[03 개발 기록/2026-11-01 단말 디자인 시스템]]을 참고한다.
