# 상태 표기 규칙

이 볼트의 구현 상태는 아래 세 단계만 사용한다.

> [!implemented] 🟢 구현
> 현재 Unity 씬에 연결되어 있고 실제 호출 경로와 결과 처리가 확인된 기능.

> [!partial] 🟡 부분 구현
> 데이터, UI, 기반 클래스 또는 일부 로직은 있으나 전체 플레이 흐름에 연결되지 않은 기능.

> [!unimplemented] 🔴 미구현
> 설계나 TODO만 존재하거나, 플레이 결과를 만드는 코드가 아직 없는 기능.

## 사용 규칙

- 표와 짧은 목록: `🟢 구현`, `🟡 부분 구현`, `🔴 미구현`
- 문서 대표 상태: frontmatter의 `implementation` 속성
- 강조 블록: `implemented`, `partial`, `unimplemented` callout
- Canvas: 초록색 `4`, 노란색 `3`, 빨간색 `1`
- 상태가 바뀌면 관련 문서, [[00 프로젝트/구현 현황|구현 현황]], [[TODO LIST/TODO LIST|TODO LIST]], Canvas를 함께 갱신한다.

## 판정 예시

| 기능 | 상태 | 이유 |
|---|---|---|
| 카드 기반 전투 루프 | 🟢 구현 | 선택부터 턴 실행·카드 재배분까지 연결됨 |
| 스킬 SP 모델 | 🟡 부분 구현 | 모델은 있으나 전투 이벤트에서 호출하지 않음 |
| 저장/불러오기 | 🔴 미구현 | 저장 계층이 확인되지 않음 |
