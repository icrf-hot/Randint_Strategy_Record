# 프로젝트 개요

## 한 줄 정의

카드의 숫자와 속성을 세 포지션의 대원 행동으로 변환하고, 노드형 맵을 이동하며 진행하는 명일방주 팬게임 프로토타입.

## 현재 플레이 구조

1. `Map_1F` 씬에서 현재 노드와 연결된 다음 노드를 확인한다.
2. 노드를 클릭해 카메라를 집중시키고 설명과 선택지를 연다.
3. Battle 노드 선택 시 맵의 로딩 오버레이를 페이드인하고 `Playing_Scene`을 비동기로 불러온다.
4. 전투 씬의 진입 오버레이가 문구를 표시한 뒤 페이드아웃한다. 이 동안 게임 시간은 정지하며 입력을 차단한다.
5. 진입 페이드가 끝나면 총 6장의 카드를 받는다. 각 자리는 숫자 카드가 기본이며, 확률 판정을 통과하면 묶음 전체에서 최대 1장이 특수 카드 `T`로 대체된다.
6. Front, Middle, Back 슬롯에 각 규칙에 맞게 카드를 배분한다.
7. 필요한 공격 대상까지 지정하면 전투 버튼이 열린다.
8. 공격 속도순으로 아군과 적이 한 번씩 행동한다.
9. 선택 카드와 임시 능력치 보너스를 초기화하고 새 카드를 배분한다.

현재 맵→전투 화면 전환과 첫 카드 배분 대기는 코드·씬 참조상 🟢 구현 상태다. 다만 양쪽 오버레이는 Sprite 없이 검은색 UI Image를 사용하는 임시 연출이므로 로딩 이미지 작업은 🟡 부분 구현이다. Read Only 원칙상 이번 확인은 정적 검증이며, 전투 결과를 `Map_1F`로 되돌리는 흐름도 아직 없다.

## 핵심 설계 축

| 축 | 역할 | 현재 상태 |
|---|---|---|
| 카드 | 매 라운드 행동 자원 | 🟢 구현 |
| 포지션 | Front 공격/방어, Middle 공격, Back 회복 | 🟢 구현 |
| 타기팅 | 포지션별 적 선택 제한 | 🟢 구현 |
| 턴 순서 | 공격 속도 내림차순, 동률 우선순위 | 🟢 구현 |
| 맵 | 연결 노드 탐색과 이동 가능 노드 표시 | 🟢 구현 |
| 씬 전환 | 맵 퇴장 페이드 → 비동기 로드 → 전투 진입 페이드 | 🟢 구현 |
| 로딩 화면 | 페이드·문구·점 애니메이션 | 🟢 구현 |
| 로딩 이미지 | 양쪽 오버레이의 최종 배경·연출 자산 | 🟡 부분 구현 |
| 이벤트 선택 | 선택지 표시와 노드 이동 | 🟡 부분 구현 |
| 스킬 | SP 데이터와 충전 모델 | 🟡 부분 구현 |
| 캠페인 진행 | 맵→전투→맵 복귀 및 저장 | 🔴 미구현 |

## 주요 씬

- `Title.unity`: Main Camera만 존재하는 초기 상태
- `Map_1F.unity`: 8개 노드로 구성된 3D 경로, 포커스 UI, 전투 씬 로더
- `Playing_Scene.unity`: 카드 선택, 대원 포커스, 적 생성·타기팅, 턴 실행
