# 프로젝트 개요

## 한 줄 정의

카드의 숫자와 속성을 세 포지션의 대원 행동으로 변환하고, 노드형 맵을 이동하며 진행하는 명일방주 팬게임 프로토타입.

## 현재 플레이 구조

1. `Map` 씬에서 현재 노드와 연결된 다음 노드를 확인한다.
2. 노드를 클릭해 카메라를 집중시키고 설명과 선택지를 연다.
3. `Playing_Scene`에서 총 6장의 카드를 받는다. 각 자리는 숫자 카드가 기본이며, 확률 판정을 통과하면 묶음 전체에서 최대 1장이 특수 카드 `T`로 대체된다.
4. Front, Middle, Back 슬롯에 각 규칙에 맞게 카드를 배분한다.
5. 필요한 공격 대상까지 지정하면 전투 버튼이 열린다.
6. 공격 속도순으로 아군과 적이 한 번씩 행동한다.
7. 선택 카드와 임시 능력치 보너스를 초기화하고 새 카드를 배분한다.

현재 1번과 3번 사이의 **씬 전환 및 진행 데이터 전달은 연결되어 있지 않다**.

## 핵심 설계 축

| 축 | 역할 | 현재 상태 |
|---|---|---|
| 카드 | 매 라운드 행동 자원 | 🟢 구현 |
| 포지션 | Front 공격/방어, Middle 공격, Back 회복 | 🟢 구현 |
| 타기팅 | 포지션별 적 선택 제한 | 🟢 구현 |
| 턴 순서 | 공격 속도 내림차순, 동률 우선순위 | 🟢 구현 |
| 맵 | 연결 노드 탐색과 이동 가능 노드 표시 | 🟢 구현 |
| 이벤트 선택 | 선택지 표시와 노드 이동 | 🟡 부분 구현 |
| 스킬 | SP 데이터와 충전 모델 | 🟡 부분 구현 |
| 캠페인 진행 | 맵→전투→맵 복귀 및 저장 | 🔴 미구현 |

## 주요 씬

- `Title.unity`: Main Camera만 존재하는 초기 상태
- `Map.unity`: 8개 노드로 구성된 3D 경로 및 포커스 UI
- `Playing_Scene.unity`: 카드 선택, 대원 포커스, 적 생성·타기팅, 턴 실행
