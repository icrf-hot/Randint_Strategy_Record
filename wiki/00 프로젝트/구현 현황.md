# 구현 현황

## 검증 기준

- 확인일: 2026-11-02. 현재 작업 트리 기준이며, 과거 커밋 기준점과 구분한다.
- Unity `6000.3.11f1` / uGUI / URP. 일반 검증은 C# 컴파일이며, 컴파일 성공만으로 시각·게임플레이 정확성을 주장하지 않는다.
- 최근 제한 검증: 타이틀·로비·준비·맵·전투·상점 전환, 맵 회전/설명창/카드 겹침, 전투 배속·스킵 결과 일치, 처치·승리 보상·맵 복귀, 전투 선택창의 빈/선택 상태와 글자 비율 확인.
- 전투 시간 측정은 통제된 아군 3명+적 4기 비처치 턴에서 1x 약 2.79초, 2x 1.44초, 3x 0.89초다. 모든 전투의 고정 시간이 아니다.
- 실제 마우스 조작 전수 검사, 다양한 해상도, 출시 빌드와 실기기 성능·전체 밸런스는 미검증이다.
- Build Settings: 기존 Title(0), Map_1F(1), Playing_Scene(2), Shop(3), Lobby(4), Preparation(5) 보존. Map_2F~Map_5F를 6~9에 등록.
- 상세 근거: [[03 개발 기록/2026-11-01 단말 디자인 시스템]], [[03 개발 기록/2026-11-01 전투 연출 파이프라인]], [[03 개발 기록/2026-10-15 저장·계속하기·삭제]].

## 현재 완성된 전투 루프

```mermaid
stateDiagram-v2
    [*] --> 카드배분
    카드배분 --> 승인대기: 슬롯 미완성 또는 타깃 없음
    승인대기 --> 카드배분: 추가 선택
    카드배분 --> 실행가능: 모든 조건 충족
    실행가능 --> 행동정렬: 전투 버튼
    행동정렬 --> 순차행동
    순차행동 --> 승리검사
    승리검사 --> 맵복귀: 생존 적 0명
    승리검사 --> 카드회수: 생존 적 있음
    카드회수 --> 선택초기화
    선택초기화 --> 새카드배분
    새카드배분 --> 카드배분
```
