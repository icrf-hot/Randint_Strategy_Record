# 02 Map 창 모드

상위 문서: [[04 기획/타이틀·로비 기획|타이틀·로비 기획]]

## 사용자 요구

- Map 우측 상단에 2D Square와 TMP로 버튼을 둔다. 추후 아이콘으로 교체한다.
- 이 버튼으로 설정을 열면 우측 상단에 Windows 창 모드처럼 `− / □ / ×`를 표시한다.
- `−`는 잠시 중단한다.
- `×`는 저장하고 나간다.
- `□`는 창 모드를 취소하고 Map을 전체 화면으로 돌린다. 이것은 게임 내부 연출이다.

| 조작 | 사용자 요구 | 미결정 범위 |
|---|---|---|
| 우측 상단 버튼 | 창 조작 UI 열기 | 버튼 이름, 실제 설정 항목의 포함 여부, 최초 창 크기 |
| `−` | 잠시 중단 | 로비 복귀 여부, 실행 상태 유지 범위, 복원 방법 |
| `□` | 창 모드 해제·Map 전체 화면 복귀 | 확대 연출, 입력 재개 시점 |
| `×` | 저장하고 나가기 | 로비 복귀 또는 프로그램 종료, 저장 범위·실패 처리 |

## 검토 제안 · 미확정

- 우측 상단 버튼을 `메뉴` 또는 `창 모드`로 부르고, 음량 등의 실제 설정은 로비 설정 창에서 관리한다. 사용자가 말한 설정 버튼의 최종 역할을 먼저 확정한다.
- 창 모드 진입 시 Map을 테두리·제목 표시줄이 있는 영역으로 축소한다. 표시줄 조작이 3D 노드 클릭과 겹치지 않도록 한다.
- `−`는 Map 상태를 유지한 채 로비로 최소화하고, 로비의 `실행 중인 작전기록` 표시를 눌러 복원한다.
- `×`는 저장 후 로비로 돌아가 작전 창을 닫는다. 프로그램 종료로 해석할지는 아직 확정하지 않았다.

## 미결정

- 창 모드 진입 자체가 Map 조작을 중단하는지, 축소 상태에서도 탐색할 수 있는지
- 최소화 중 시간·카메라·연출의 정지 범위와 저장 여부
- 최소화된 Map을 둔 채 새 게임·이어하기를 누를 때 기존 런을 어떻게 처리할지
- 노드 이동·Battle 전환 중 버튼을 사용할 수 있는지
- 창 이동·크기 조절 지원 여부. 사용자가 요청한 범위로 자동 포함하지 않는다.

저장 정책은 [[04 기획/04 저장과 이어하기|저장과 이어하기]]에서 관리한다.

## 확인 기준

- TMP와 Square만으로 `− / □ / ×`를 구분한다.
- `□`로 복귀한 뒤 Map 화면·카메라·노드 입력이 정상 동작한다.
- `−`의 중단·복원과 `×`의 저장·종료가 확정된 정책대로 구분된다.
- 창 UI 클릭이 뒤쪽 Map 노드로 전달되지 않는다.
