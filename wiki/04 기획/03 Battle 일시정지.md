# 03 Battle 일시정지

상위 문서: [[04 기획/타이틀·로비 기획|타이틀·로비 기획]]

## 사용자 요구

- 전투 화면인 `Playing_Scene` 우측 상단에 2D Square와 TMP 버튼을 둔다. 추후 아이콘을 적용한다.
- 버튼을 누르면 게임이 중단된다.
- 중단 창은 TMP와 Square로 만들며 선택지는 `나가기`, `계속하기` 두 개만 표시한다.
- `계속하기`로 전투를 재개한다.

## 검토 제안 · 미확정

- 계속하기는 카드 선택·타깃·대원 HP·퇴각·행동 순서 등 중단 직전 상태를 유지한다.
- 나가기는 전투 진입 직전 Map 상태로 저장하고 로비로 돌아간다. 이어하기 시 전투를 처음부터 시작한다. 이는 AI 제안이며 사용자 확정 정책이 아니다.
- 위 정책 채택 시 `현재 전투는 처음부터 다시 시작됩니다`라는 TMP 안내를 표시하되 버튼은 두 개만 유지한다.

## 중단 범위와 검증 과제

게임 중단은 시간 배율뿐 아니라 진행 중인 전투 처리와 입력을 포함해야 한다. 기존 전투·전환 연출에는 실시간 기준 대기가 있으므로 시간 배율을 0으로 만드는 것만으로 모든 진행이 멈춘다고 단정하지 않는다.

| 대상 | 확인할 내용 |
|---|---|
| 입력 | 카드 선택·타깃 변경·전투 실행을 차단하고 중단 창 입력만 허용 |
| 행동 | 피해·회복·퇴각·재배치·다음 행동이 중단 중 진행되지 않는지 |
| 연출 | 카드 회수·배분, 카메라 포커스 등 연출의 정지 범위 |
| 복원 | 중단 전 시간 배율과 카메라·선택 상태를 복원할지 정책 확정 |
| 종료 경계 | 결과 화면·씬 전환 중 일시정지 버튼 사용 가능 여부 |

## 미결정

- 카드 선택 중·행동 실행 중 모두 일시정지를 허용할지
- 나가기의 복귀 목적지와 저장 여부·저장 시점
- 전투를 나갔다가 재진입할 때 적·카드 난수 결과를 유지할지 다시 생성할지
- 포커스 감속 상태에서 중단 후 계속하기 시 복원할 시간 배율
- 결과 화면·씬 전환 중 버튼을 잠글지

저장·재진입 정책은 [[04 기획/04 저장과 이어하기|저장과 이어하기]]에서 관리한다.

## 확인 기준

- 중단 창의 버튼은 나가기·계속하기 두 개다.
- 중단 중 전투 결과가 변하지 않고 게임 입력이 차단된다.
- 계속하기 후 행동 누락·중복 실행과 카드·타깃 상태 손실이 없다.
- 나가기와 이어하기는 확정된 저장 정책을 따른다.
