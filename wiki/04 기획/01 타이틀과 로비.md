# 01 타이틀과 로비

상위 문서: [[04 기획/타이틀·로비 기획|타이틀·로비 기획]]

## 사용자 요구

- PRTS의 배신으로 작전기록을 신뢰할 수 없게 되어 내부 데이터에 직접 접근한다는 컨셉을 전달한다.
- Title에서 로비로 진입한다. 로비는 Windows XP 느낌의 UI/UX를 보여준다.
- 초기 창에는 세 항목만 둔다: 설정, 폴더 형태의 게임 이어하기, 문서 형태의 새 게임 `.exe`.
- 새 게임을 누르면 게임을 시작한다.
- 초기에는 이미지를 넣지 않고 TMP로 무엇인지 표시한다. 사각형을 이용한 임시 UI 이후 아이콘을 적용한다.

| 초기 항목 | 요구 기능 | 임시 표시 제안 · 미확정 |
|---|---|---|
| 설정 | 설정 화면 진입 | `설정` TMP + Square |
| 폴더 | 게임 이어하기 | `작전기록 폴더` TMP + Square |
| 문서형 `.exe` | 새 게임 시작 | `새 작전기록.exe` TMP + Square |

## 검토 제안 · 미확정

- 로비를 내부 기록 관리 데스크톱으로, Map과 Battle을 그 안에서 실행하는 프로그램으로 표현한다.
- Title에서 정상 검증 표시와 독립 검사 불일치를 짧게 보여준 뒤 로비로 진입한다. 구체적인 연출·문구·재생 시간·건너뛰기 여부는 미정이다.
- 기존 압축 해제·검사·재압축 문구와 로비 진입 표현을 연결한다.
- 저장 데이터가 없으면 폴더 내부에 `저장된 작전기록 없음`을 표시한다. 버튼 비활성화 방식과 비교해 결정한다.
- 창 제목 표시줄·테두리·버튼의 입체감을 단색 사각형으로 표현한다. XP의 특정 이미지나 배경을 초기 자산으로 추가하지 않는다.

## 미결정

- Title의 입력 방식과 로비 진입 시점, PRTS 배신을 처음부터 얼마나 공개할지
- 초기 창의 위치·크기·닫기 가능 여부와 바탕화면·작업 표시줄 사용 여부
- 설정에 포함할 기능과 설정 창의 닫기·적용 방식
- 새 게임의 기존 저장 처리·초기화 범위 및 최초 Map 위치
- 이어하기의 저장 슬롯 수와 파일 선택 화면

저장과 새 런 정책은 [[04 기획/04 저장과 이어하기|저장과 이어하기]]에서 관리한다.

## 확인 기준

- 세 항목을 TMP만으로 구분할 수 있고, 추후 아이콘 추가를 전제로 한다.
- 새 게임은 결정된 초기화 정책에 따라 Map 플레이를 시작한다.
- 설정·이어하기의 구체적인 기능은 미결정 정책을 확정한 뒤 확인한다.
